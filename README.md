# Thực hành Bảng Danh sách Sản phẩm trong HTML

Bài thực hành luyện tập sử dụng thẻ bảng `<table>`, `<tr>`, `<th>`, `<td>` để hiển thị danh sách sản phẩm.

## Nội dung bài tập
- File chính: `index.html`
- Tiêu đề `<h1>`: "Danh sách sản phẩm"
- Các cột trong bảng:
  - Tên sản phẩm
  - Giá
  - Số lượng
- Danh sách 5 sản phẩm công nghệ chi tiết
